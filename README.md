# Milky Client
1. Install Node.js 20+
2. `npm install`
3. `npm start`   (installer: `npm run dist`)
First run opens the official Microsoft sign-in window. Fabric, Fabric API, Sodium, Lithium, FerriteCore, ImmediatelyFast, More Culling, Dynamic FPS and ModernFix are downloaded from Modrinth into your profile before every launch.
